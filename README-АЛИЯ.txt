КАК ДОБАВЛЯТЬ УЧЕБНЫЕ МАТЕРИАЛЫ
- Домашняя работа №1: data/lessons/lesson-1.json; №2: lesson-2.json, и т. д.
  JSON должен содержать id="lesson-1", number=1, status="available", title, subtitle, blocks и т. д.
- Грамматика: дополняйте массив window.GRAMMAR_DATA в data/grammar-data.js.
- Словарь: дополняйте массив window.VOCABULARY_DATA в data/vocabulary-data.js.
- Аудио: в audio/, картинки: в images/.
- Уведомления о выполненном ДЗ запускаются после «Отправить преподавателю»; они требуют 
  опубликованного сайта, доступной общей Edge Function, доступа бота в чат и работающей БД.
- Для отправки уведомления о НОВОМ ДЗ предусмотрен .github/workflows/notify-new-materials.yml;
  нужны переменные GitHub Actions: TELEGRAM_NOTIFICATIONS_ENABLED=true,
  SITE_BASE_URL, STUDENT_ID=alia, SUPABASE_PROJECT_ID=zqzgarvmpqqqaobeicpc;
  секрет NOTIFY_WEBHOOK_SECRET. Запуск вручную с lesson_id, например lesson-1.
  В уроке также должны быть status="available" и notification.enabled=true.
